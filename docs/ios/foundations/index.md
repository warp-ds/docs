# iOS foundation

How the Warp foundations are exposed in the Warp iOS package: themes, colour tokens, typography, spacing, shape and elevation. For the design guidance behind them, which applies to every platform, see the [Design Language](/design-language/).

To add the package to your app, follow [Get started on iOS](/get-started/ios/). The package supports iOS 18 and later, and its default branch is `main` ([warp-ds/warp-ios](https://github.com/warp-ds/warp-ios)).

## Topics

- [Theming](/ios/foundations/theming) — choosing a brand, how the theme reaches your views, and light and dark mode.
- [Tokens](/ios/foundations/tokens) — semantic colour tokens, component colours and data visualisation colours, for SwiftUI and UIKit.
- [Typography](/ios/foundations/typography) — the Warp text styles, how to apply them and how they scale with Dynamic Type.
- [Spacing](/ios/foundations/spacing) — the spacing scale and semantic layout values.
- [Shape](/ios/foundations/shape) — corner radius and border width values.
- [Elevation](/ios/foundations/elevation) — shadows and elevated surface colours.
