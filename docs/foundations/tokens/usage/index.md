# Usage

A token name says what the colour is for, followed by an optional variant and state. For example, `--w-s-color-background-primary-subtle-hover` is the hover state of the subtle variant of the primary background.

## Variants

| Variant         | Meaning                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------- |
| Static          | Does not change colour in light and dark modes.                                                   |
| Inverted        | Used for specific high-contrast surfaces, components, or accents that flip the surrounding theme. |
| Inverted subtle | Same as “Inverted” but a more subtle variant.                                                     |
| Inverted static | Static variant of the inverted colour that does not change in light and dark modes.               |

## States

| State  | Meaning                                                                  |
| ------ | ------------------------------------------------------------------------ |
| Hover  | The state shown when you hover over an interactive surface with a mouse. |
| Active | The pressed state when you click on an interactive surface.              |
