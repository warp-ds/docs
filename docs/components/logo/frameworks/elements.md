# Logo - Elements

Brand logos for use on the web.

<ComponentsStatus />
<FrameworkTabs />
<ThemeSwitcher />

## Usage

Brand logos for web are available in SVG format. You can use them as you would any image by providing an `alt` attribute and set its `width` and `height` in the markup to avoid layout shifting.

<elements-example>

```html
<img alt="Blocket" width="120" height="26" src="https://assets.blocket.se/pkg/@warp-ds/brand-logos/~1/blocket.svg" />
```

</elements-example>

### Variants

Logos that need it have an inverted variant designed for dark backgrounds. Add the `-inverted` suffix to your logo file name to use it, for example `dba-inverted.svg`.

:::info Not all logos have an inverted variant

FINN, Blocket and Tori don’t have inverted variants because the logos are designed to work on light and dark backgrounds, so always use their regular versions regardless of background.

:::
