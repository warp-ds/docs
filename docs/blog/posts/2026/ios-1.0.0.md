# Warp iOS release 1.0.0

## 2026-10-20

#### Standalone NotificationBadge

Warp now includes `Warp.NotificationBadge` as a standalone view. Read more on the [Notification badge iOS page](/components/notification-badge/frameworks/ios).

#### Segmented control badges

Segmented control supports badges, and `Warp.NotificationBadge` is integrated into the segmented control. Read more on the [Segmented control iOS page](/components/segmented-control/frameworks/ios).

#### Primary action style for alerts and confirmation dialogs

Actions in `AlertDialog` and `ConfirmationDialog` can use the primary style. See the [Alert iOS page](/components/alert/frameworks/ios) and the [ConfirmationDialog iOS page](/components/confirmation-dialog/frameworks/ios).

#### Accessibility

- VoiceOver support for tappable controls

#### Sendable conformance

- Component enums conform to `Sendable`
