In Warp Elements, a button group is not a separate element. Set `type="button"` on a [checkbox group](/web/components/checkbox/code.md) (multiple selection) or a [radio group](/web/components/radio/code.md) (single selection).

## Styling and API

Button groups use the styling API and attributes of the group element you build them from: see [`w-checkbox-group`](/web/components/checkbox/code.md) or [`w-radio-group`](/web/components/radio/code.md).
