# Radio buttons

<ComponentsStatus />

Radio buttons allow users to select a single option from a button group.

## Example

<ThemeSwitcher />

<elements-example>

```html
<w-radio-group label="Package size" name="package-size" type="button">
	<w-radio value="small">Small</w-radio>
	<w-radio value="medium">Medium</w-radio>
	<w-radio value="large">Large</w-radio>
</w-radio-group>
```

</elements-example>
