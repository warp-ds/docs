# Web

Everything you need to build Warp experiences for the web. **Warp Elements** (web components) is the primary implementation. React, React 19 and Vue remain available as legacy implementations.

- [Get started on the web](/get-started/web/) — install Warp, set up styles and fonts.
- [Web foundation](/web/foundations/) — CSS classes, customization, dark mode, keyboard and font guidance.
- [Web components](/web/components/) — overview, usage, code and accessibility for each component.
- [Patterns](/patterns/) — guidance for recurring user tasks (none documented for Web yet).

The shared [Design Language](/design-language/) applies to every platform.
